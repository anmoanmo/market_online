# 部署指南

本项目当前以根目录 `compose.yml` 作为推荐部署入口，旧的 Windows + 虚拟机 + 多窗口手动启动方式不再作为小组共享默认流程。

请阅读：

- [../docs/部署与运行.md](../docs/部署与运行.md)
- [../docs/隐私与密钥检查.md](../docs/隐私与密钥检查.md)
- [../docs/测试与验收清单.md](../docs/测试与验收清单.md)

快速命令：

```bash
cp .env.example .env
docker compose up -d --build
```

真实邮箱、支付宝沙箱、对象存储配置只填写在本机 `.env` 中，不要提交到仓库。默认对象存储使用 Compose 内置 MinIO，控制台地址为 `http://localhost:9101`。
